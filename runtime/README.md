# AWTRIX2 Host runtime

Copy your complete, legally obtained AWTRIX2 Host directory here before running `install.sh`.

At minimum it normally contains `awtrix.jar` (or `awtrix2-host.jar`), `www/`, `languages/`, `Apps/`, and `config/`. The runtime is excluded from Git because configuration files can contain credentials and the upstream Host binary is not redistributed here.
